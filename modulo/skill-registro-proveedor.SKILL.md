---
name: registro-proveedor
description: Conocimiento operativo para preparar registros de proveedor.
---

El proceso usa datos del repositorio maestro, genera formularios y prepara soportes para revision humana. Los datos bancarios solo se usan si la plantilla los solicita y nunca se agregan al borrador de correo. Un soporte vencido o ausente bloquea la firma; un campo faltante debe declararse, no inventarse.
